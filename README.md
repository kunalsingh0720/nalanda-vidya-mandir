# Nalanda Vidya Mandir — website

Official website for Nalanda Vidya Mandir, a CBSE day school for Nursery through Grade 12, founded 1962.

## Structure

- index.html — page markup
- css/style.css — all styles
- js/main.js — all behaviour (nav, reveal animations, counters, lightbox, demo forms)
- images/gallery/ — campus-life photos for the Gallery section
- images/instagram/ — photos and captions pulled from @nvm.patasang for the Instagram section

See images/README.md for how to add a new photo.

## Local development

Open index.html directly in a browser, or serve the folder with any static file server.

## Deployment

Hosted as a static site via GitHub Pages, deployed from the main branch.
